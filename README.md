# MyCV

A personal CV website introducing my background as a Professional Architect and my journey into software development.

## About Me

I am a SACAP-registered Professional Architect with a Master of Architecture from the University of the Free State. I am currently studying full-stack software engineering at HyperionDev.
My goal is to combine architecture and technology to build practical applications for the design and construction industry.

## Website Sections

- Profile and introduction
- Biography
- Skills and competencies
- Education
- Work experience
- Contact details and LinkedIn profile

## Technologies Used
- HTML
- CSS
- Tailwind CSS through the Play CDN

## Project Files
- `index.html` — Page structure and content.
- `style.css` — Custom colours, gradients, cards and image styling.

## View Locally
1. Download the project files.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in your browser.
